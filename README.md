# Bayesian-Optimal-Transport-Flow-Matching-with-Conditional-Wasserstein-Distances
This code is based on the paper **Conditional Wasserstein Distances with Applications in Bayesian OT Flow Matching** available at https://arxiv.org/abs/2403.1870 and https://github.com/JChemseddine/Conditional_Wasserstein_Distances.

It contains implementation for the experiments of conditional generation task on CIFAR-10 with different OT solvers such as EMD and Sinkhorn.
